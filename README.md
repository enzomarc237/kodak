# YouTube Video to Interactive HTML Deep Explanations

This tool converts any YouTube video into an interactive HTML document with deep explanations. It fetches the video's transcript, analyzes the content, and generates in-depth explanations for key concepts. It can also generate media (images, videos, audio) to enhance the learning experience.

## Features

*   **YouTube Video Processing:** Input any YouTube video URL to get started.
*   **Interactive HTML Output:** The generated content is an easy-to-navigate HTML document.
*   **Deep Explanations:** AI-powered explanations for complex topics discussed in the video.
*   **Media Generation:** Automatically generate images, videos, and audio to supplement the text.

## Tech Stack

*   **Frontend:** React, Vite, Tailwind CSS
*   **Backend:** Node.js, Express
*   **AI:** OpenAI GPT-4
